Login Page Explanation

1. Purpose

-- This page allows patients to log in to the Healthcare Patient Portal.
--Users enter their email and password to access their account.

2. Background

--The page uses a dark blue gradient background (#0f172a to #2563eb).
--It gives a modern and professional healthcare look.

3. Login Box

--A blue login card (#1e40af) is placed at the center of the screen.
--It contains all login-related fields.

4. Healthcare Logo

--A healthcare icon 🏥 is displayed at the top.
--Below it, the title Healthcare Patient Portal is shown.

5. Input Fields

--Email field: User enters their email address.
--Password field: User enters their password.

6. Login Button

--When the user clicks the Login button, the form is checked.

7. Validation
--The JavaScript function checks:

-If the email field is empty → shows "Please enter your email".
-If the password field is empty → shows "Please enter your password".
-If both are filled → shows "Login Successful!".

8. Additional Links

--Forgot Password? for password recovery.
--Sign Up for creating a new account.

# Task 3 - Edge Case Handling

The User Authentication feature handles the following edge cases:

1. Empty email field
2. Empty password field
3. Invalid email format
4. Password length less than 6 characters
5. Password and Confirm Password mismatch

Appropriate alert messages are displayed to guide the user and prevent invalid form submission.
